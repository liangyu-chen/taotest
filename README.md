# 排班排程系統

自動排班系統，包含帳號密碼登入、後台管理與自動產生員工班表。

- 前端：React + Vite + TypeScript
- 後端：Node.js + Express
- 資料庫：Neon（PostgreSQL）

## 功能

- **帳號登入**：JWT 登入，管理員 / 一般使用者兩種角色
- **班表總覽**：月曆顯示每人每天班別與負責的工作項目；管理員可點擊、拖曳微調或換班，也可把整月班表**匯出成 Excel**（早班時間藍色、晚班時間紅色）
- **自動排班**：依班別人數需求與員工排休偏好，依「目標時數」公平分配並產出整月班表；超過「連續工作天數上限」或撞上排休時會在總覽標示提醒
- **排休與偏好**：員工自行標記排休日、沒空時段（可指定起訖時間）與偏好的班別，也可 Ctrl+C / Ctrl+V 快速複製貼上
- **員工管理**：區分**正職**（每班固定時數）與**工讀**（每班時數、每週目標時數可自由安排），並可設定每位員工的代表顏色與工作技能
- **工作項目**：管理員可定義吧台、內場等工作項目；員工勾選自己會做的工作項目（至少一項），排班時指派當天負責的項目
- **班別與人力**：設定早 / 晚 / 跨夜班時段與顏色，以及「平日 / 週末 / 例假日」三種日型的各班人力需求
- **公休日**：整家店不營業的日子。當天不排班、自動排班也會跳過；可單日或批次設定，設為公休日時會清空當天既有排班
- **排班規則設定**：營業時間、正職 / 工讀每班時數、工讀每週目標時數、例假日日期清單、連續工作天數上限
- **帳號管理**：新增帳號、重設密碼、指派角色與綁定員工

### 排班規則說明

以「6 人、2 位正職 + 4 位工讀」為例：

1. **員工類型**（〈員工管理〉）：正職每班固定 8 小時；工讀可依員工個別設定「每班時數」（如 6 小時）與「每週目標時數」。
2. **營業時間**（〈排班規則設定〉）：一～五 12:00–24:00。
3. **人力需求**（〈班別與人力〉）：早班平日 1 人、週末 / 例假日 2 人；晚班每天 1 人。
4. **例假日**（〈排班規則設定〉）：填寫日期後，該日會以「例假日」的人力需求排班。
5. 自動排班時，會依每人「目標時數」的比例平均分配班次，避免有人過忙。

### 鎖定日期

在〈班表總覽〉點選日期格子（可多選），再用上方「🔒 鎖定所選」鎖定。鎖定的日期：

- 自動排班完全不會更動該日班表（保留、不新增、不移除）
- 管理員也無法手動增刪人員（「＋」與拖曳都會停用），需先解鎖才能編輯
- 格子右上角有 🔒 / 🔓 圖示可單日切換

## 快速開始

### 1. 安裝套件

```
npm install
```

### 2. 建立 Neon 資料庫

1. 到 [Neon](https://neon.tech) 建立一個免費專案。
2. 在專案 → **Connect** → **Connection string** 複製連接字串（`postgresql://...`）。
3. 填進 `.env` 的 `DATABASE_URL`。

> 首次啟動時，系統會自動建表並寫入預設管理員與班別，不需要手動建表。

### 3. 設定環境變數

複製 `.env.example` 為 `.env` 並填入：

```
DATABASE_URL=postgresql://user:password@host/database?sslmode=verify-full
JWT_SECRET=請改成一長串隨機文字
ADMIN_USERNAME=admin
ADMIN_PASSWORD=admin123
```

### 4. 啟動開發伺服器

```
npm run dev
```

- 前端：http://localhost:5173
- 後端 API：http://localhost:3001

### 5. 第一次登入

用 `.env` 中的 `ADMIN_USERNAME` / `ADMIN_PASSWORD`（預設 `admin` / `admin123`）登入，進入〈帳號管理〉後立刻建立自己的帳號並**修改密碼**。

## 操作流程建議

1. 到〈工作項目〉新增吧台、內場等工作項目。
2. 到〈員工管理〉新增員工，並設定每位員工的工作技能（至少一項）與代表顏色。
3. 到〈帳號管理〉為員工建立登入帳號，並**綁定員工**，員工即可自己標記排休。
4. 到〈班別與人力〉確認班別與每天人力需求。
5. 到〈排班規則設定〉填入營業時間、例假日與連續工作天數上限。
6. 到〈自動排班〉選擇月份並「產生班表」。
7. 到〈班表總覽〉檢查（人力 / 工作項目不足時會顯示警示），手動微調後可**匯出 Excel** 給同事。

> 補充：整家店公休的日子，先在〈班表總覽〉設為**公休日**，自動排班才會跳過那天。

## 建立正式版本

```
npm run build
npm start
```

伺服器會同時提供 API 與前端網頁，連線 http://localhost:3001 即可使用。

## 部署注意事項

- 正式上線請務必修改 `JWT_SECRET`，並透過 HTTPS 傳輸。
- 目前登入密碼以 bcrypt 雜湊儲存在 Neon `users` 表。
- `.env` 已加入 `.gitignore`，請勿上傳到公開儲存庫。
